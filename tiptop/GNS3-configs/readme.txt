GNS3 Legacy Configurations

This folder contains the configurations of the 9 routers from the original GNS3 topology.

These configurations are used as a basis to configure the new containerlab topology.

Please note the following mapping of names:
- SpaceBody-R1 -> Orbiter2
- SpaceBody-R2 -> Orbiter1
- SpaceBody-R3 -> SpaceBody-R1
- SpaceBody-R4 -> SpaceBody-R2
